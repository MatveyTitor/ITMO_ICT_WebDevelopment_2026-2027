# ЛР1. Работа с сокетами

Титор Матвей, группа K3339. Вариант задания 2: **3 — площадь трапеции**
(порядковый номер 31 в журнале).

Все скрипты написаны на Python 3 и используют только стандартную
библиотеку (`socket`, `threading`, `urllib.parse`).

## Как запускать

В каждом задании сначала в одном терминале запускается сервер,
затем в другом — клиент(ы):

```bash
# Задание 1 — обмен приветствиями по UDP (порт 9000)
python task1_udp/server.py
python task1_udp/client.py

# Задание 2 — площадь трапеции по TCP (порт 9001, вариант 3)
python task2_tcp/server.py
python task2_tcp/client.py          # ввод: a, b, h — основания и высота

# Задание 3 — раздача index.html по HTTP (порт 8080)
cd task3_http && python server.py    # затем открыть http://localhost:8080/
cd ..                                # вернуться в корень работы

# Задание 4 — многопользовательский чат по TCP (порт 9002)
python task4_chat/server.py
python task4_chat/client.py         # в нескольких терминалах

# Задание 5 — веб-сервер GET/POST, журнал оценок (порт 8081)
python task5_webserver/server.py    # затем открыть http://127.0.0.1:8081/
```

Остановить сервер: `Ctrl+C` в его терминале.

> Если `python` не запускается (заглушка Windows Store — процесс молча
> завершается с кодом 49), используйте лаунчер `py`: `py task1_udp/server.py`.

## Что где лежит

| Папка            | Задание                                                      |
|------------------|--------------------------------------------------------------|
| `task1_udp/`     | 1. Обмен «Hello, server» / «Hello, client» по UDP            |
| `task2_tcp/`     | 2. Вычисление площади трапеции по TCP (вариант 3)            |
| `task3_http/`    | 3. Раздача HTML-страницы из `index.html` вручную собранным HTTP-ответом |
| `task4_chat/`    | 4. Многопользовательский чат: TCP + `threading`              |
| `task5_webserver/` | 5. Веб-сервер: разбор GET/POST, журнал оценок, сгруппированный по дисциплинам |
